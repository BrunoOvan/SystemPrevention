Como funciona?

1

Você relata o contato suspeito recebido.

2

O agente DELTA faz perguntas para entender o caso.

3

O sistema salva a denúncia no banco de dados.

4

Um protocolo é gerado para acompanhamento.

Dados que serão coletados

  • Canal do contato
  • Relato da tentativa de golpe
  • Solicitação feita pelo golpista
  • Registro no banco de dados
  • Protocolo de acompanhamento
